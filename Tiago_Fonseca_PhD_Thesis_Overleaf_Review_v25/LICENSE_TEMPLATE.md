# Template Attribution

The visual structure and public command interface of this working project are based on the **FEUP Dissertation format** by João Canas Ferreira and João Correia Lopes, distributed under a Creative Commons Attribution 4.0 licence.

This repository contains a project-local adaptation intended to create a self-contained working draft. It is not presented as an official or certified replacement for the latest FEUP/PRODEI submission files. Before submission, the candidate should compare the project with the current template and programme requirements.
